01 / PROJECT OVERVIEW

This project explores the possibility of repurposing a salvaged smartphone LCD panel into a DIY projection system.

Instead of treating the smartphone as a finished device, the experiment focused on the LCD panel itself, its optical path, and the software pipeline used to render the image.

CORE IDEA

Recover useful components from older hardware and re-engineer them into an experimental display system.

03 / HARDWARE FRAMEWORK

Salvaged LCD Panel

A 5.0-inch LCD panel from a 2016 Android smartphone was modified by stripping its reflective layers to make the display matrix transparent.

Light Engine

The modified LCD was integrated into a light-engine arrangement so the display matrix could be illuminated and projected through the optical path.

04 / OPTICAL ALIGNMENT

A parallel twin Fresnel lens array was aligned to project the bare LCD matrix onto a matte, high-gain surface.

Modified LCD Matrix → Light Engine → Twin Fresnel Lens Array → Projection Surface

05 / THERMAL MANAGEMENT

The build used a dual-stage isolated fan configuration described in the original project notes as a 12V induction loop.

The cooling arrangement was designed as a separate component of the physical assembly to manage thermal load.

06 / SOFTWARE INTEGRATION

The software side focused on customized image rendering and processing, with adjustments made to the rendering pipeline and graphics configuration.

Rendering Configuration

Custom rendering adjustments designed to improve image output and display performance.

Image Processing

Modified GLSL shader configurations and OpenGL ES image filtering.

Rendering Configuration

scale=ewa_lanczossharp

Additional processing included custom unsharp-mask matrices and GLSL shader configurations.

The goal was to improve edge-to-edge text legibility and color-profile calibration while overriding the legacy platform's default blurry hardware filtering.
