ANDROID INTO WALKMAN / PC INSTALLATION & TRANSFORMATION TUTORIAL

01 / ABOUT THE TUTORIAL

From Android to Walkman.

This tutorial documents the process of setting up Android Into Walkman, my Android customization project.

I created this video in 2023 to show the installation process and how I configured the smartphone to become a Walkman-inspired music player.

The video also demonstrates how I used a PC to manage selected preinstalled Android applications as part of preparing the device for the setup.

02 / INSTALLATION & TRANSFORMATION

The setup process.

The tutorial follows the process of preparing the Android device, installing the required components, and setting up the Walkman-inspired experience.

STEP 01

Prepare the Android device

Prepare the smartphone and get it ready for the Android Into Walkman setup.

STEP 02

Manage preinstalled applications

Use a PC tool to disable or uninstall selected preinstalled applications that are not needed for the setup.

STEP 03

Install the required components

Install and configure the applications and components needed for the Walkman experience.

FINAL SETUP

Complete the transformation

Bring the setup together into an Android smartphone with a Sony Walkman-inspired music environment.

03 / PC TOOL USED

ADB AppControl.

ADB AppControl was the PC tool I used to manage selected preinstalled applications on the Android device during the preparation process.

I used ADB AppControl to uninstall selected preinstalled applications from the device. The tutorial also explains that applications can be disabled instead if you are unsure whether they should be removed.

App installation for the Walkman setup was done directly on the Android smartphone. ADB AppControl was used for managing preinstalled applications.
