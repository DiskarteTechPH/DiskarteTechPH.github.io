01 / ABOUT THE PROJECT

A Walkman-inspired Android experience.

Android Into Walkman is an Android customization project developed by DISKARTE TECH PH in 2022.

The project brings together a collection of applications and Sony Music-inspired elements to create a dedicated music experience on Android.

It is a personal project built around the idea of bringing the classic Walkman experience into a modern Android smartphone.
