01 / ABOUT THE PROJECT

A different way to use an old smartphone.

This project started with a simple idea: what if an old Android smartphone could feel more like a dedicated music player?

I didn't want to simply install several music applications and leave them as they were. I wanted to bring different functions together into one customized Sony Walkman-style experience.

The project involved modifying existing Android applications and adapting their integrations to work differently from their original purpose.

I used APKTool M to work with existing APK files and modify selected components for the setup.

It took me approximately two weeks to work on this project, around 2022. The result was a Sony Music-centered Android environment designed to make the phone feel like a dedicated Walkman-style device.

This page documents a personal Android customization project from around 2022. Some smaller development details may be missing because I no longer remember every modification I made.
02 / INSIDE THE BUILD

How I actually modified it.

The interesting part of this project wasn't just installing applications. It was adapting existing Android apps and changing how their integrations worked together.

I started with an existing launcher that was originally designed for a Spotify-based setup. I used APKTool M to modify the existing integration and redirect its music function toward Sony Music.

Rather than keeping the original Spotify-oriented experience, I wanted Sony Music to become the primary interface of the setup.

I also worked on existing Sony app extensions. Instead of using their original functions, I repurposed selected extensions to connect with other applications.

MODIFICATION 01

Spotify Launcher → Sony Music

The original launcher was designed around Spotify. I modified its existing music integration using APKTool M so it would work with Sony Music instead.

MODIFICATION 02

Wikipedia Extension → Browser

I repurposed an existing Sony Wikipedia-related extension and adapted it for browser integration. This gave the customized interface another useful function beyond music.

MODIFICATION 03

YouTube Extension → YouTube Music

I also modified an existing Sony YouTube-related extension to work with YouTube Music instead.

FINAL INTEGRATION

A Sony Music-centered Interface

The modified launcher and repurposed extensions were brought together into a music-focused Android experience, with Sony Music as its primary interface.

Not just an app installation

The main idea was to make existing applications work together in a different way. I wasn't developing Sony Music or the original launcher from scratch. I was modifying and adapting their existing integrations for my own setup.

I spent around two weeks experimenting with the components until I got the experience I wanted.

Looking back, this was one of those projects where the process of figuring things out was just as interesting as the final result.

Development note: The descriptions above are based on the modifications I personally remember. Exact APK structures, code changes, and additional steps are not documented because this project dates back to around 2022.
