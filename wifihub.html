01

Project Overview

Ang Wi-Fi Media Hub ay isang simpleng local website na naka-host mismo sa Android phone. Gagamit tayo ng Python HTTP server para ma-access ang files gamit ang ibang device na nakakonekta sa parehong local network.

Android Host

Ang Samsung Galaxy Note 3 ang magsisilbing host device kung saan naka-save ang website at media files.

Python Server

Si Python ang magse-serve ng website at files sa local network gamit ang HTTP.

Wi-Fi Network

Gagamit ng Xiaomi Wi-Fi Extender para makakonekta ang host at client devices sa parehong network.

Client Device

Maaaring gumamit ng compatible browser sa iPhone, Android phone, tablet o computer.

IMPORTANT: Local network project ito. Hindi kailangan ng public hosting para ma-access ang website sa parehong Wi-Fi network.
02

Requirements

01. Android Phone

Samsung Galaxy Note 3 o compatible Android device na kayang magpatakbo ng Termux.

02. Termux

Terminal application para makapag-install at makapagpatakbo ng Python.

03. Wi-Fi Extender

Xiaomi Wi-Fi Extender o router na nagbibigay ng local network connection.

04. Client Device

iPhone, Android phone o computer na may compatible web browser.

03

Install Termux and Python

STEP 01

Update Termux Packages

Buksan ang Termux at i-update muna ang package list at installed packages. 

pkg update && pkg upgrade -y
STEP 02

Install Python

I-install ang Python na gagamitin para sa local web server. 

pkg install python -y
TIP: Hintaying matapos ang installation bago magpatuloy sa susunod na steps.
04

Create Project Folders

STEP 01

Create Main Folder

Gagawa tayo ng main folder na tatawaging wifihub. 

mkdir -p ~/wifihub/files
STEP 02

Enter Project Directory

cd ~/wifihub
FOLDER LOCATION: Ang project ay nasa Termux home directory, hindi sa Android system root folder.
05

Create the Media Hub Website

STEP 01

Create index.html

Gamitin ang nano para gumawa ng HTML file. 

nano index.html
STEP 02

Insert Your Website Code

Ilagay ang HTML code ng iyong Media Hub website. Maaari mong gamitin ang sariling design, navigation, music player, video player at document links.

STEP 03

Save the File

Sa nano editor, gamitin ang sumusunod: 

CTRL + O
ENTER
CTRL + X
FILE NAME: Dapat eksaktong index.html ang pangalan ng main website file.

07

Start the Python Web Server

STEP 01

Start the Server

Siguraduhing nasa wifihub directory ka bago patakbuhin ang command. 

cd ~/wifihub
python -m http.server 8080 --directory ~/wifihub
STEP 02

Check the Server Message

Kapag gumagana na, makikita ang ganitong message: 

Serving HTTP on 0.0.0.0 port 8080
STEP 03

Find Your Android Local IP

Tingnan ang Wi-Fi network details ng Android phone para malaman ang local IP address nito.

Halimbawa ng local address: 

192.168.1.17
SERVER ADDRESS: Palitan ang example IP ng aktuwal na IP address ng iyong Android phone. Gamitin ang port 8080.
08

Connect Your iPhone

STEP 01

Connect to the Same Wi-Fi

Ikonekta ang iPhone sa parehong Wi-Fi network na ginagamit ng Android host device.

STEP 02

Open a Compatible Browser

Buksan ang browser na available sa iyong device. Sa setup na ito, ginamit ang iDNS mini-browser para ma-access ang local website.

STEP 03

Enter the Local Website Address

I-type ang local IP address ng Android host kasama ang port number. 

http://192.168.1.17:8080

Palitan ang 192.168.1.17 kung iba ang IP address ng iyong Android phone.

EXPECTED RESULT: Lalabas ang Media Hub website kung parehong connected sa network ang devices at tumatakbo ang server.
COMPATIBILITY NOTE: Hindi lahat ng lumang browser ay kayang mag-play ng lahat ng MP4 codec. Kung hindi gumana ang video, maaaring browser o video format compatibility ang dahilan.
09

Troubleshooting

Website Not Loading

• Tingnan kung tumatakbo pa ang Python server.
• I-check kung tama ang local IP address.
• Siguraduhing parehong network ang ginagamit ng devices.
• Tiyaking tama ang port number na 8080.

Music Not Playing

• Tingnan kung tama ang MP3 filename.
• Siguraduhing nasa files folder ang audio.
• I-check ang audio link sa HTML.
• Subukan ang ibang compatible browser.

Video Not Playing

• I-check kung tama ang MP4 filename.
• Tingnan kung suportado ng browser ang video codec.
• Maaaring mas compatible ang MP4 na may H.264 video at AAC audio, pero hindi ito garantiya sa lumang browser.

Server Stopped

Kapag naisara ang Termux o natigil ang Python server, kailangan itong patakbuhin ulit. 

cd ~/wifihub
python -m http.server 8080 --directory ~/wifihub
